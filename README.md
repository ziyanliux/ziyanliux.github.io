# Ziyan Liu · Personal Website

静态学术主页，白底、炭黑文字、酒红色强调。无需安装依赖或构建，直接在浏览器中打开 `index.html` 即可。

## 文件

- `index.html`：个人介绍、新闻、论文、教育经历、学术服务和奖项。
- `styles.css`：配色、排版和响应式样式。
- `script.js`：论文筛选、历史新闻、移动导航和图片预览。
- `images/`：原有头像与论文图片，未修改。
- `vendor/`：本地图标库与许可证，网页运行时无需访问 CDN。
